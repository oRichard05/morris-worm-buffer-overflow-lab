Why it happened

Our simplified C model writes bytes without respecting the name[16] boundary. Characters beyond it can modify the adjacent role.

How we fix it

Check the input length before copying. A 16-byte character array can store at most 15 characters plus the terminating \0.

The real incident: November 1988

The Morris Worm exploited an unchecked input in the UNIX fingerd service, among other weaknesses. Its stack buffer overflow could redirect execution. Our fictional menu and ADMIN field are teaching devices, not features of the historical attack. Administrators addressed the vulnerability through software patches and safer input handling.
