MEMORY INVESTIGATION · EDUCATIONAL RECONSTRUCTION

What happened?

A local C program copied data beyond its name buffer into the next field.

Memory after the request

24 bytes: 16 for the name, 8 for the role.

Name buffer · offsets 0–15 Role field · offsets 16–23

Before the fix

char name[16];
char role[8];

// No check for the name field boundary

Our controlled model writes across a field boundary inside one stack object.

After the fix

if (strlen(input) >= sizeof(session.name)) {
    puts("INPUT REJECTED");
} else {
    memcpy(session.name, input, strlen(input) + 1);
}

Reject the input before copying if it cannot fit, including the terminating byte.

The real 1988 incident

The Morris Worm exploited a stack buffer overflow in the UNIX fingerd service. Unlike our simplified role-field demonstration, the historical flaw could redirect program execution. The worm also used other methods to spread. Administrators patched or disabled vulnerable services and replaced unsafe input handling.
