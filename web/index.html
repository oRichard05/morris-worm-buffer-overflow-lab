What the real 4.3BSD code did

char line[512];
gets(line);

The original fingerd used an unbounded read into a 512-byte local buffer. The Morris Worm exploited that error on vulnerable VAX systems to redirect execution. Unlike that exploit, our smaller classroom model only demonstrates adjacent-field corruption.

A safer input read must respect the size of the destination buffer, including the final NUL byte. Updating or disabling vulnerable services was part of the historical response.
